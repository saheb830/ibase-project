About This Project

The Library Management and Book Reservation System is a web-based application designed to manage books, check availability and allow students to reserve books online.

📚 Book Management

Manage and display the library book collection.

🔍 Book Search

Search books by title, author and category.

📌 Reservation

Students can reserve available books.

📊 Dashboard

View books, issued books and reservation statistics.
